# 升级说明（覆盖解压三步）

> 适用版本：v1.0.0 → v1.1.x 及以后。全程不需要卸载、不需要装任何东西。

## 三步升级

1. **把新 zip 解压到任意临时目录**（不要直接解压到旧目录里，避免嵌套）
2. **把解压出来的 `Sketchfab下载器` 文件夹整个拖进旧目录，选择「替换目标中的文件」**
   - 旧目录指你上次解压出来的那个文件夹（里面有 `Sketchfab下载器.exe` 和 `_internal`）
   - Windows 会问「是否替换」→ 全选「替换」
3. **双击 `Sketchfab下载器.exe`**，标题栏看版本号是否变成新版（如 `v1.1.0`）

升级后建议点一次工具栏的「关于 / 诊断」，确认依赖自检全绿。

## 为什么不会丢设置

| 数据 | 位置 | 覆盖解压是否会丢 |
|---|---|---|
| 保存目录、并发数、更新源、`decrypt_backend` | `%APPDATA%\Sketchfab下载器\config.json` | **不会**（在用户目录，不在程序目录） |
| 便携模式配置 | `程序目录\config.json` | **会**（覆盖解压会替换它）——便携模式的代价，故意如此 |
| 已下载的模型 | 你自己选的输出目录 | **不会** |
| 崩溃日志 `error.log` | 程序目录 | 会被覆盖，一般无需保留 |

配置查找顺序（v1.1 起）：

1. 若 `程序目录\config.json` 存在（或加了 `--portable`）→ **读写它**（便携模式）
2. 否则 → 读写 `%APPDATA%\Sketchfab下载器\config.json`
3. 读取时若上述目标不存在，会兜底读另一个位置，所以老版本遗留在程序目录里的配置**仍然生效**；
   下一次保存时会自动迁移到新的单一位置

想手动打开数据目录：工具栏「关于 / 诊断」→ 底部「打开数据目录」。
想主动回到便携模式：在程序目录空建一个 `config.json`（内容 `{}` 也行），或启动时加 `--portable`。

## 回滚到旧版

1. 把旧的 `Sketchfab下载器` 文件夹留着别删 —— 回滚就是把它拖回来覆盖
2. 若怀疑是「WASM 解密路径」引起的问题，不用回滚整个程序：
   在 `config.json` 里加 `"decrypt_backend": "legacy"`，程序会把资源目录从 `PATH` 临时剔除，
   引擎自动回落到随包的 `binzDecrypt.exe`（v1.1 仍保留它）

## 常见问题

**Q：解压后被杀软删了某个 dll / exe？**
A：加白名单后重新解压整包。「关于 / 诊断」里显示 `MISSING` 的那一项就是被删的文件。

**Q：提示缺少 Node.js？**
A：正常情况下 `_internal\node.exe` 会被自动找到（`--env` 的 `NODE_LOOKUP` 行能看到）。
显示 `MISSING` 说明包不完整，重新解压。

**Q：新版本比旧版本小了很多，是不是功能被砍了？**
A：v1.1 只删了重复文件和永不加载的 wasm 包，功能一个没少；
把「关于 / 诊断」里的版本号与 CHANGELOG 对一下即可确认。
