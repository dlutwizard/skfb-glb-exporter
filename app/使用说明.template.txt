Sketchfab 模型下载器 v{{VERSION}}
==========================================

一个本地小工具：粘贴模型链接 → 自动下载几何体 → 自动解密贴图 → 导出 Blender 能直接打开的 .glb

不需要安装，不需要装 Python、Node.js 或任何运行库。

本说明由构建脚本自动生成（版本 v{{VERSION}}｜构建日期 {{BUILD_DATE}}｜Python {{PYTHON_VER}}）
解压后体积约 {{SIZE_ONEDIR_MB}} MB，实测启动约 {{STARTUP_SEC}} 秒。


一、怎么用
----------
1. 把压缩包解压到任意位置（比如 D:\Sketchfab下载器\）
2. 双击里面的「Sketchfab下载器.exe」
3. 把 Sketchfab 模型链接粘进「模型链接」框 —— 一行一个，可以一次粘十几个
   支持三种写法（可混着粘）：
     https://skfb.ly/p9HSv                              （短链）
     https://sketchfab.com/3d-models/xxx-<32位ID>       （完整链接）
     直接粘 32 位 ID                                     （也可）
4. 选保存位置（第一次会自动选一个存在的目录，之后记住上次选择）
5. 「同时下载数」选几个并行跑（可选 1-5，默认 3）
6. 点「开始下载」，进度条按模型个数推进
7. 点「打开输出目录」

并行下载时日志每行前面带 [序号 模型名] 前缀，能分清是哪个模型在报进度。
写错或重复的链接会自动去掉（按 32 位 ID 判重）。

下载前每个模型会先显示面数、授权，以及作者是否开放了官方下载。

注意：不要只把 exe 单独拿走，必须整个文件夹一起移动 ——
exe 旁边的 _internal 文件夹是程序的一部分，缺了打不开。


一之二、搜索模型（v1.2.0 新增，v1.2.4 加图片预览）
--------------------------------------------------
顶栏最右侧是琥珀色的「♥ 打赏支持」按钮，点开可看到收款码；本工具完全免费，打赏自愿。
顶栏右侧有三个页签：「下载」「模型搜索」「3D 预览」（当前页签下方有琥珀色横线）。切到「模型搜索」：

1. 输入关键词（中英文都行），回车或点「搜索」
2. 可勾「只看可下载」、切换排序（相关度 / 最多喜欢 / 最新发布 / 最多浏览）
3. 用「上一页 / 下一页」翻页（每页 24 条）
4. 双击某条 → 在浏览器打开模型原页
5. 选中一条或多条（Ctrl / Shift 多选）→ 点「下载选中」，
   链接自动加进「下载」页签的链接框并立即开始下载
6. 选中任意一条，右侧「预览」面板会显示大图和模型信息

结果里的「仅浏览」表示作者没有开放下载，会被自动跳过并提示。
列表会显示面数、许可协议和动画段数；注意本工具导出的是静态几何 + 贴图，
不含动画和骨骼。

搜索走 Sketchfab 官方公开接口，免登录、免 API key，只发送关键词与分页信息。
本版只搜 Sketchfab 站内，不聚合其它站点（其它站需要各自的 API key 或没有
公开搜索接口）。结果列表每行带缩略图，选中任意一条可在右侧「预览」面板看大图；
图片走官方公开 CDN 异步加载并缓存，用系统自带组件转码，不增加额外依赖。


二、输出内容
------------
输出目录\<模型名>-<ID前8位>\
    ├── <模型名>.glb           ← 成品，材质贴图都内嵌在里面
    ├── <模型名>.gltf          ← 备用格式（转换失败时用它，贴图在 textures\ 里）
    ├── info.json              ← 元信息：模型名、作者、授权、主交付物、贴图清单
    ├── model_file.bin         ← 网格数据（原始分片，重转时用）
    ├── file.osgjs             ← 场景结构
    └── textures\              ← 散装贴图（已解密，和 GLB 里的一致）

说明：
  - 解密用的 key.txt / key2.txt 默认**不会**留在输出目录（v1.1.8 起），
    需要排障时设环境变量 SKFB_KEEP_INTERMEDIATES=1 再跑。
  - info.json 里的 "output" 指向主交付物，"deliverables" 列出全部可用文件。

Blender 导入：File → Import → glTF 2.0 → 选 .glb
按 Z 切到 Material Preview 才能看到材质效果。


二之二、把模型转成 3D 打印文件（v1.5.0：水密重建）
------------------------------------------------
下载页有一块琥珀色描边的「3D 打印导出（水密重建）」分区：

  [成品最长边 244 mm]  [ ] 适配 H2D Pro 平台   质量 [精细]   [◆ 高级 3D 打印转换…]

点按钮 → 选任意 .glb / .gltf / .stl / .obj / .ply / .3mf / .off
（不限于本工具下载的模型）→ 程序在**同目录**生成：

    <模型名>.stl    二进制 STL，所有切片软件都认；单色，只有几何
    <模型名>.3mf    OPC 容器，单色；Bambu Studio 可直接打开

高级重建做了什么：
  - 体素化后填洞、合并壳体，最后用 Marching Cubes 提取等值面；
  - 输出的实体保证边界边 0、非流形边 0（水密），不是简单格式转换；
  - 按「成品最长边」等比缩放；244 mm 约等于 1:18 车模；
  - 勾选「适配 H2D Pro 平台」则自动按 350x320x325 mm 留 8 mm 余量；
  - 质量档位：标准 / 精细 / 超精细（约 60 万 / 120 万 / 200 万面预算）。

发布包已内置高级转换 worker.exe（含 numpy / scipy / scikit-image / trimesh），
目标电脑不需要安装 Python 或 Anaconda，解压即可使用。

只有从源码运行时才需要外部环境：

    pip install numpy scipy scikit-image trimesh
    set SFD_ADVANCED_PYTHON=D:\Anaconda\python.exe   （可选，指定解释器）

找不到高级环境时，仍可点右下角的「基础转换（仅几何）」使用旧的纯标准库导出，
但那份结果不保证水密，只适合应急。

限制：
  - STL / 3MF 是单色，贴图颜色不会保留；
  - 体素间距决定最小细节，默认精度下约 1 mm 以下的小特征会被平滑；
  - 破洞很大的模型会按外轮廓补成实体，窗缝、格栅等镂空可能被填平；
  - 骨骼 / 动画 / 形变只取静态顶点。

二之三、3D 文件预览（v1.4.0：本地 WebGL）
--------------------------------
顶栏切到「3D 预览」页签，点「打开模型…」选一个 .glb / .stl / .3mf，
或者点「预览输出目录最新模型」直接看刚下载 / 刚转换出来的文件。
程序会启动只监听 127.0.0.1 的临时服务，并用默认浏览器打开本地 WebGL 查看器；
Three.js 随软件离线打包，不联网、不上传文件、不需要装任何 3D 软件。

怎么用：
  左键拖拽 = 旋转      滚轮 = 缩放      右键拖拽 = 平移
  双击画布 或 点 Fit = 自动适配模型
  快捷键：W 线框 / G 网格 / R 自动旋转 / A 坐标轴

查看器右下角显示三角形数、顶点数、尺寸和格式。模型直接按原始网格显示，
不再为了预览做顶点合并降面；GLB 保留材质与贴图，STL 为琥珀单色，
3MF 读取包内颜色。预览不会改变打印文件，导出的 STL / 3MF 仍使用完整网格。

支持三种格式：
  .glb   保留材质、贴图与 PBR 反射，姿态按 glTF 的 Y-up 约定显示
  .stl   二进制与 ASCII 都认，无颜色信息时按琥珀色单色显示
  .3mf   读取 OPC 容器，支持颜色、装配与 transform

这一功能同样只用 Python 标准库实现，不增加任何额外依赖，发布包体积基本不变。


三、流程原理（三步）
--------------------
[1/3] 解析链接：短链跟随跳转，取出 32 位模型 UID，查官方 API 拿模型信息
[2/3] 下载几何体：调用内置下载引擎，抓公开预览器的 .binz 分片并解密
[3/3] 导出材质：读本地已下好的贴图并逐张解密（4K/8K 也一样），
      再把 osgjs 场景转成 glTF，贴图内嵌进 .glb

贴图只下载一次：引擎负责下载，转换器直接读本地文件并对受保护的图解密回写，
所以 textures\ 里的图和 .glb 里的图是同一批（早期版本会下两遍，v1.1.8 已合并）。

解密只有一条后端：Node + WASM（程序会把随包的 node.exe 放进 PATH，引擎自己找得到）。
早期的 binzDecrypt.exe 传统后端因来源许可问题已从发布包移除，
配置里再写 "decrypt_backend": "legacy" 也会自动按 WASM 处理。

五、为什么是文件夹而不是单个 exe
--------------------------------
做成单个 exe 也能跑，但每次启动都要把全部内部文件解压到临时目录，
实测要几十秒才出窗口 —— 用户会以为程序卡死，反复双击。

文件夹形态只在解压压缩包时花几秒，之后每次启动约 {{STARTUP_SEC}} 秒。

所以：分发包用 zip，别用单文件 exe。


六、命令行用法（可选）
----------------------
不开界面也能批量下，适合脚本化：

  Sketchfab下载器.exe --run "链接1,链接2" --out "D:\模型" --conc 3

参数：
  --run      链接，多个用逗号/分号/空格分隔
  --out      输出目录（默认挑一个存在的目录）
  --conc     并发数 1-5（默认 2）
  --no-full  只下几何体，不导出带材质的 GLB

诊断与信息参数：
  --env          打印各依赖解析到的实际路径、Node 查找结果、实际解密后端
  --version      打印版本号
  --version --json  以 JSON 输出结构化版本信息
  --selftest     只建界面不显示，成功输出 SELFTEST_OK
  --portable     强制把配置写在程序目录（便携模式）

八、开发环境（只有你自己改代码时才需要）
----------------------------------------
  源码仓库： https://github.com/dlutwizard/skfb-glb-exporter （MIT）
  界面：     app\sketchfab_gui.py
  打印导出： app\print_advanced.py + app\advanced_print_worker.py（水密重建）
基础导出： app\print_export.py（GLB → STL / 3MF，纯标准库）
  下载引擎： dist_engine\main.py、dist_engine\textures.py
  转换器：   app\convert.mjs（Node，读本地贴图并内嵌到 GLB）
  构建：     python build\build.py   （跑测试 → 打包 → 瘦身 → 自检 → 出 zip）
  测试：     python -m pytest -q    （干净检出即可跑，无需发布包）
  Python：   需要带 tkinter 的解释器（托管版没有 tkinter）

程序找依赖的顺序是「随程序附带的 → 本机固定路径」，所以源码直接运行
和打包成 exe 都能工作，不会互相干扰。

打包时的一个坑（已修）：PyInstaller 会带进较新的 OpenSSL，它在读取
Windows 系统证书存储时可能抛 ASN1: NOT_ENOUGH_DATA。程序启动时会把
默认的 https 证书源换成 certifi 自带的证书文件，绕开系统证书存储。


九、限制
--------
能下：公开模型（包括作者没开下载按钮的）、带贴图的、加密贴图可还原
不能下：付费模型、私密模型、需要登录才能看的模型
动画：**只导出静态几何 + 材质贴图，不含动画 / 骨骼 / 形变**。
      模型含动画时，下载日志和 info.json 会明确写出来（animations.supported=false），
      不会假装是"完整模型"。需要动画请用作者官方下载或 Sketchfab 导出。
打印导出：STL 单色、3MF 只有常量色；贴图颜色不能无损转进 3MF，
      蒙皮 / 动画只取静态顶点，点线 primitive 会跳过（详见「二之二」）。
贴图：个别模型可能有个别贴图解不出来，这时日志会打警告、
      info.json 的 texture_warnings 里也有记录，不会被悄悄吞掉
速度：小组件一两分钟，高面数车模约一分半下载 + 几秒转换
并行：同时下载数开太大不会更快 —— 解密贴图那步吃 CPU，带宽也有限，
      实测 2-3 个最划算；5 个以上反而互相拖慢
